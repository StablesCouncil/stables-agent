Ambassador

Ambassadors help merchants in their region get fully listed on Stables: profiles, QR flows, and local support. Merchants who only run a storefront use My shop for their listing and Create Invoice; use Exchange (under Shops & Exchange in More) when you need instant conversion between Wables balances.

How you register (preview): join by paying 10 Big Macs (value indexed by country using the Big Mac Index) as a direct Ambassador registration, or start by onboarding your first shop—registration can align with that flow. Exact launch terms will follow Council governance.

Proposed merchant listing fee (showcase): when a shop is onboarded through this pathway, the merchant pays 20 Big Macs (same index), split 50% protocol / 50% ambassador.

Webshop linking & QR

Online shops can point customers to Stables the same way as a physical checkout: a QR code or payment link encodes your receive address, amount, currency, and an order or invoice reference. Scanning or opening the link starts (or deep-links) the Stables MiniDapp so the payer confirms in one flow—mirroring what you build in Create Invoice.

▦
QR preview (demo)
Address · amount · order ID

Your webshop or POS generates this QR from the Merchant API kit (below) or from a static “Pay with Stables” page that calls the same payload format the Council documents.

Merchant API kit

The Council will ship a small integration kit so developers can add “Pay with Stables” without re‑implementing crypto details: helpers to build signed or canonical payment requests, render QR images, validate callbacks, and copy‑paste examples (e.g. Node, PHP, or serverless). Watch the public org for the published repo and versioned docs.

StablesCouncil on GitHub

This preview does not call a live API yet; the button opens the organisation where the kit will land.

Webhooks & callbacks

Is “webhook” the right word? Yes, for your server: a webhook is an HTTPS endpoint you host that Stables (or a Council notifier) can POST to when a payment is confirmed, so your webshop can mark an order paid, send email, or restock—without polling the chain. The same idea is often called a callback URL or IPN (instant payment notification) in other gateways.

You will register the URL in merchant settings, verify signatures with a shared secret or public key, and respond quickly with 200 OK. Exact payload and headers will ship with the API kit.
