## Facebook Cover Photo Guidelines

### Dimensions
- **Desktop**: 820x312px (displayed)
- **Mobile**: 640x360px (cropped from center)
- **Safe Zone**: Avoid critical elements in bottom-left 170x170px (profile picture overlap)

### File Requirements
- **Format**: PNG (recommended for transparency effects)
- **Max Size**: 100KB recommended for fast loading
- **Color Space**: sRGB

### Upload Instructions
1. Navigate to Facebook Page
2. Click "Edit Cover Photo" → "Upload Photo"
3. Select `facebook_cover_banner.png`
4. Adjust positioning if needed (Facebook allows repositioning)
5. Save changes

## Design Rationale

### Why This Layout?
- **Left-anchored wordmark**: Follows Stables design constraint for hero layouts (brand elements anchor left)
- **Profile picture safe zone**: Ensures wordmark remains visible even with profile picture overlay
- **Right-side tagline**: Balances composition and provides messaging without cluttering
- **MINIMA attribution**: Top-right placement ensures visibility without interfering with main branding

### Visual Hierarchy
1. **Primary**: STABLES wordmark (largest, most prominent)
2. **Secondary**: Tagline (readable, supporting message)
3. **Tertiary**: BUILT ON MINIMA badge (mandatory attribution)
4. **Accent**: Symbol (brand reinforcement, visual interest)
