# Stables Console

> **The user interface for Stables**—a decentralized money platform built on Minima.

⚠️ **Alpha Software**: This is early-stage software. Use at your own risk.

---

## 🌐 About

The **Stables Console** is a web-based interface for interacting with the Stables. It allows users to:

- ✅ Mint Stables (the Stablescoin)
- ✅ Manage collateral positions
- ✅ Track portfolio health
- ✅ Participate in governance (coming soon)

---

## 🚀 Features

### Current (Alpha)
- **Mint Stables**: Create Stablescoins by depositing collateral
- **Position Management**: Monitor and adjust your collateralization ratio
- **Dashboard**: Real-time view of your holdings and protocol stats
- **Pseudonymous**: No accounts, no KYC—just your Minima address

### Coming Soon
- **Governance Interface**: Vote on proposals, view Council decisions
- **Advanced Analytics**: Historical data, risk metrics
- **Mobile Optimization**: Responsive design for all devices

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript (Vanilla)
- **Blockchain**: Minima
- **Smart Contracts**: Minima Script (MiniDAPP)
- **Hosting**: Decentralized (runs locally via Minima node)

---

## 📦 Installation

### Prerequisites
- Minima node installed and running
- Modern web browser (Chrome, Firefox, Brave recommended)

### Setup
```bash
# Clone the repository
git clone https://github.com/stables-council/console.git

# Navigate to the directory
cd console

# Install as a MiniDAPP on your Minima node
minima -installminidapp console.mds.zip

# Access via your Minima node
# URL: http://localhost:9003/stables-console
```

> [!CAUTION]

- Always verify transaction details before signing
