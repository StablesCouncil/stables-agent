## 📖 About Stables

**Stables** is a decentralized money platform that provides stability without centralized control.

### Key Features
- **Decentralized Stablescoin**: Stables is pegged to USD using over-collateralized positions
- **Pseudonymous**: No KYC, no central authority
- **Built on Minima**: Every user runs a full node—true decentralization
- **Council Governance**: Managed by The Council (forming)

### Core Values
- **Secure**: Fully on-chain, auditable
- **Pseudonymous**: Your money, your privacy
- **Unstoppable**: Censorship-resistant by design
