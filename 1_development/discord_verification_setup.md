# Discord Verification Setup Guide (Native Method)
**Date:** 2026-01-20  
**Purpose:** Set up Discord's built-in verification - NO BOTS REQUIRED

---

## 🎯 WHAT IS DISCORD NATIVE VERIFICATION?

Discord has built-in verification called **"Membership Screening"** that requires:
- ✅ No bots
- ✅ No third-party permissions
- ✅ No external apps
- ✅ Built directly into Discord

**How it works:**
1. New member joins server
2. They see a welcome screen with your rules
3. They must accept rules to enter
4. They can then see all channels

---

## 📋 STEP-BY-STEP SETUP

### **Step 1: Enable Community Features**

1. Click your server name (top left) → **Server Settings**
2. Scroll down to **Enable Community**
3. Click **Get Started**
4. Follow the setup wizard:
   - Set **#rules** as your Rules or Guidelines channel
   - Set **#announcements** as your Community Updates channel
   - Click **Finish Setup**

---

### **Step 2: Enable Membership Screening**

1. Still in **Server Settings**
2. Go to **Safety Setup** (left sidebar under "Community")
3. Scroll to **Membership Screening**
4. Toggle it **ON**
5. Click **Set up Membership Screening**

---

### **Step 3: Configure Membership Screening**

**Add Your Rules:**

Copy and paste this into the screening form:

```
Welcome to Stables Discord!

By joining this server, you agree to follow these rules:

1️⃣ BE RESPECTFUL
• Treat everyone with respect
• No harassment, hate speech, or discrimination
• Keep discussions civil

2️⃣ STAY ON TOPIC
• Keep discussions relevant to Stables and Minima
• Use appropriate channels

3️⃣ NO SPAM OR SELF-PROMOTION
• No advertising other projects
• No repetitive messages

4️⃣ NO FINANCIAL ADVICE
• We never sell tokens
• Don't ask for or give financial advice
• DYOR (Do Your Own Research)

5️⃣ HELP EACH OTHER
• Answer questions when you can
• Welcome new members
• Build the community together

6️⃣ REPORT ISSUES
• Report rule violations to moderators
• Don't engage with trolls or scammers

By clicking "Submit", you agree to follow these rules.
```

**Settings:**
- ✅ Check "Require members to accept rules before they can talk or DM"
- Click **Save Changes**

---

### **Step 4: Set Channel Permissions (Optional)**

If you want extra control over what new members see:

**For #welcome and #rules:**
1. Right-click channel → **Edit Channel** → **Permissions**
2. **@everyone** role:
   - ✅ View Channel: ON
   - ❌ Send Messages: OFF

**For all other channels:**
- Default permissions work fine with Membership Screening
- Members automatically get access after accepting rules

## � MANAGING MEMBERSHIP SCREENING

**To edit rules:**
1. Server Settings → Safety Setup → Membership Screening
2. Click "Edit"
3. Update your rules text
4. Save changes

**To disable:**
1. Server Settings → Safety Setup → Membership Screening
2. Toggle OFF

**To view pending members:**
1. Server Settings → Membership Screening
2. See list of members who haven't accepted yet

## ❓ TROUBLESHOOTING

**"I don't see Enable Community"**
- Make sure you're the server owner
- Server must have at least 2 channels

**"Membership Screening option is grayed out"**
- Enable Community Features first
- Set Rules and Updates channels

**"Members can see channels without accepting"**
- Check that Membership Screening is enabled
- Verify "Require acceptance" is checked

**"I want to change the rules"**
- Server Settings → Safety Setup → Membership Screening → Edit
