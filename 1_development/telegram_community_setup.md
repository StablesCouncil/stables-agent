# Stables Community - Telegram Group Setup Guide

## Step 1: Create the Group

1. Open Telegram
2. Click **New Group**
3. Add at least one contact (you can remove them later)
4. Name: **Stables Community**
5. Click **Create**

## Step 2: Convert to Supergroup

1. Go to **Group Info** → **Edit**
2. Tap **Group Type** → **Public Group**
3. Choose username: `@StablesCommunity` (or similar)
4. Convert when prompted

## Step 3: Configure Settings

### Basic Settings
- **Description:**
  ```
  The official Stables community discussion group.
  
  Talk about the money platform, ask questions, share ideas, and connect with the team and other users.
  
  📢 Official announcements: @StablesCouncil
  
  Built on MINIMA
  ```

### Group Photo
- Upload the Stables symbol from `vested_assets/stables_symbol.png`

### Permissions
1. Go to **Edit** → **Permissions**
2. **What can members do:**
   - ✅ Send Messages
   - ✅ Send Media
   - ✅ Send Stickers & GIFs
   - ✅ Send Polls
   - ✅ Embed Links
   - ✅ Add Members
   - ❌ Pin Messages (admin only)
   - ❌ Change Group Info (admin only)

### Slow Mode
- Enable **Slow Mode**: 30 seconds (prevents spam)

### Link to Channel
1. Go to your **Stables Council** channel
2. **Edit** → **Discussion** → **Link Discussion Group**
3. Select **Stables Community**
4. This allows comments on channel posts

## Step 4: Set Group Rules

Pin this message in the group:

```
🎯 **Welcome to Stables Community!**

This is the place to discuss everything about Stables - the money platform built on Minima.

**Guidelines:**
✅ Be respectful and constructive
✅ Ask questions, share ideas, help others
✅ Keep discussions on-topic (money, payments, Stables)
✅ No spam, scams, or promotional content

**Links:**
📢 Announcements: @StablesCouncil
🐦 X: @StablesCouncil
📸 Instagram: @stablescouncil

Built on MINIMA

Welcome to the Council! 🏛️
```

## Step 5: Create Admin Structure

### Recommended Admin Roles:
1. **Creator** (you) - Full permissions
2. **Moderators** (2-3 trusted members):
   - Delete messages
   - Ban users
   - Pin messages
   - Manage chat

### Bot Setup (Optional but Recommended):
- Add **@GroupHelpBot** for moderation tools
- Add **@Rose** for advanced admin features
- Add **@Combot** for analytics

## Best Practices

### Moderation
- Respond quickly to questions
- Remove spam/scams immediately
- Welcome new members personally
- Keep conversations on-topic

### Engagement
- Ask discussion questions weekly
- Share updates from development
- Host AMAs (Ask Me Anything) sessions
- Celebrate milestones with the community

### Cross-Promotion
- Mention group in channel posts
- Add to website footer
- Include in email signatures
- Share in other social media
