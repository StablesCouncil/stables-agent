Now that you have Business Manager set up, create the Page through it (not directly from your personal account):

### Create the Page

1. **In Business Manager**, go to "Pages" in the left menu

2. **Click "Add" → "Create a New Page"**

3. **Page Setup**:
   - Choose: **Business or Brand**
   - Page name: **Stables**
   - Category: **Financial Service** (primary)
   - Add secondary category: **Technology Company**

4. **Username** (can be set after page creation):
   - Preferred: `@StablesCouncil`
   - Alternative: `@Stables` or `@StablesMoney`
   - URL will be: `facebook.com/StablesCouncil`

5. **Page Description** (initial - you'll expand this later):
   - "Money that is truly yours. Secure, Pseudonymous and Unstoppable. Built on MINIMA."

> [!TIP]

- Beta testing invitations
