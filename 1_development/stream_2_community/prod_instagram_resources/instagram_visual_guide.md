## Typography Recommendations

### Headlines
- Font: Inter, Outfit, or similar modern sans-serif
- Weight: Bold (700)
- Color: White (#ffffff)

### Body Text
- Font: Inter or System UI
- Weight: Regular (400)
- Color: Light gray (#e5e7eb)

### Accents
- Color: Neon cyan (#67e8f9)
- Use sparingly for emphasis

## Instagram-Specific Optimization

### File Specifications
- **Format**: PNG or JPEG
- **Quality**: Maximum (100%)
- **Color Profile**: sRGB
- **Size**: Under 8MB per image

### Engagement Elements
- **First Comment**: Post hashtags in first comment (not caption) for cleaner look
- **Alt Text**: Always add descriptive alt text for accessibility
- **Geotag**: Consider tagging relevant blockchain/tech locations

### Story Stickers
- Poll: "Are you ready for unstoppable money?"
- Question: "What matters most to you: Security, Privacy, or Freedom?"
- Link sticker: Direct to GitHub presentation

## Asset Creation Workflow

### If Creating from Scratch:
1. Extract Master Symbol from `master_symbol.png`
2. Extract Master Wordmark from `master_wordmark_transparent.png`
3. Verify transparency against magenta (#ff00ff) background
4. Composite on dark gradient background
5. Add text overlays with brand typography
6. Export at 1080px width minimum

### If Adapting Presentation:
1. Take high-quality screenshots of presentation slides
2. Crop to 1080x1080px or 1080x1350px
3. Ensure text remains legible at mobile size
4. Add Instagram-specific formatting (borders, backgrounds)
