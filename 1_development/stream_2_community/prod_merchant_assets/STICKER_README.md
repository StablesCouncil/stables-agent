# Stables Shop Sticker - "We Accept Stables"

Official sticker design for shops and merchants to display that they accept Stables payments.

## Files

- **`sticker-we-accept-stables.svg`** - Standard size (400x200px) for digital use
- **`sticker-we-accept-stables-print.svg`** - High-resolution version (600x300px) for printing
- **`sticker-we-accept-stables.html`** - Preview page with specifications

## Design Specifications

### Dimensions
- **Standard:** 400x200px (2:1 aspect ratio)
- **Print:** 600x300px (scalable to any size)

### Colors (Official Brand Palette)
- Background: `#0b0f14` (Dark navy/black)
- Primary Text: `#e6edf3` (Light grey)
- Secondary Text: `#9fb0c0` (Muted grey)
- Accent: `#67e8f9` (Electric cyan)
- Gradient: White → Cyan → Purple

### Typography
- Font: Inter (Google Fonts)
- "We Accept": 32px, weight 700
- "STABLES": 42px, weight 900 (gradient text)
- "Digital Payments": 14px, weight 500

### Design Elements
- Glassmorphism card background
- Cyan glow effects
- Brand symbol (S logo) on left
- Horizontal layout optimized for shop windows

## Usage

### For Digital Use
1. Use `sticker-we-accept-stables.svg` directly
2. Can be embedded in websites, apps, or social media
3. Can be converted to PNG/JPEG if needed

### For Printing
1. Use `sticker-we-accept-stables-print.svg`
2. Recommended print sizes:
   - **Small:** 4" x 2" (10cm x 5cm)
   - **Medium:** 6" x 3" (15cm x 7.5cm)
   - **Large:** 8" x 4" (20cm x 10cm)
3. **Print Requirements:**
   - Print on adhesive vinyl or sticker paper
   - Works on both light and dark backgrounds
   - Best on transparent/clear stickers for shop windows
   - Minimum resolution: 300 DPI for print quality

### Integration with Official Logo
**Note:** The current SVG uses a placeholder "S" symbol. For production use:

1. Replace the circular "S" placeholder with the official Stables symbol
2. Use the master symbol from: `2_current/assets/brand_masters/master_symbol.png`
3. Convert to SVG path or embed as base64-encoded image
4. Maintain the same size and position (left side, centered vertically)
