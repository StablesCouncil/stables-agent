Stables Shop Sticker

Official sticker design for shops and merchants to display that they accept Stables payments. Features the official Stables logo, "Pay in STABLES Here" messaging, and Minima attribution.

Design Layout

  • "Pay in" - Top text in muted grey
  • "STABLES" - Main brand name with gradient (white → cyan → purple)
  • "Here" - Call-to-action in cyan accent color
  • "made possible by Minima" - Attribution at bottom
  • Logo Symbol - Official Stables symbol on the left

Design Specifications

  • Format: SVG (scalable vector graphics) - can be printed at any size
  • Dimensions: 400x200px (2:1 aspect ratio) - standard sticker size
  • Colors: Official brand palette (#0b0f14 background, #67e8f9 cyan accent)
  • Typography: Inter font family (matches brand guidelines)
  • Style: Glassmorphism effect with cyan glow accents

Files Included

  • sticker-we-accept-stables.svg - Standard size (400x200px) for digital use
  • sticker-we-accept-stables-print.svg - High-resolution version (600x300px) for printing
  • sticker-we-accept-stables.html - Preview page (this file)

Usage Instructions

For Digital Use: Use the standard SVG file. It references logo-symbol.png in the same directory. Make sure both files are in the same folder when using.

For Printing: Use the print version SVG. Recommended print sizes:

  • Small sticker: 4" x 2" (10cm x 5cm)
  • Medium sticker: 6" x 3" (15cm x 7.5cm)
  • Large sticker: 8" x 4" (20cm x 10cm)

Print Requirements: Print on adhesive vinyl or sticker paper. The design works on both light and dark backgrounds, but looks best on transparent/clear stickers for shop windows.

Logo Embedding (For Standalone Use)

The SVG files reference logo-symbol.png as an external file. For a truly standalone sticker (e.g., for printing services that require a single file), you can embed the logo as base64:

  1. Convert logo-symbol.png to base64
  2. Replace the <image href="logo-symbol.png" ...> line with: <image href="data:image/png;base64,[BASE64_STRING]" ...>

Note: The current file reference works fine when both files are in the same directory, which is suitable for most use cases.
